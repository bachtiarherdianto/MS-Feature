# Study on Learning from Past Solutions

## Overview
This repository contains the data analysis associated with our paper:

[***Feature-Guided Metaheuristic with Diversity Management for Solving the Capacitated Vehicle Routing Problem***](https://doi.org/10.1016/j.ejor.2025.12.029)

The study investigates how learning from past solutions can be used as a foundation to improve metaheuristic performance for solving the **Capacitated Vehicle Routing Problem (CVRP)** through feature-based guidance mechanism.

For implementation details of the proposed metaheuristic algorithm, please refer to [MS-CVRP](https://github.com/bachtiarherdianto/MS-CVRP) repository.

## Repository Structure

### `dataset.csv`

Contains solutions generated by:

* The [optimal](https://openreview.net/forum?id=yHiMXKN6nTl) solver
* The [MNS-TS](https://doi.org/10.1016/j.cie.2017.03.022) algorithm

The dataset includes:

* Instance features
* Solution features

All features are described in detail in the paper.

### `main.ipynb`

The main notebook used to reproduce the analysis and experimental results presented in the paper.

### `Module.py`

Contains all supporting functions and utilities used throughout the analysis.

### `mymodel/`

Stores serialized (pickle) files of the trained machine learning models.
> **Note:** You can download the files at **[Google Drive](https://drive.google.com/drive/folders/1XV8x7FYPh2et7MIqZwt0pelGZTM3tmlE?usp=sharing)**. After downloading, place the files in the `mymodel/` directory to use the models.

### Dependencies

The project requires Python 3.9 or higher and the following packages:

* numpy

* matplotlib
* seaborn
* plotly
* shap
* xgboost
* lightgbm

All required package versions and detailed dependency specifications are listed in the `requirement.txt` file.

## Reproducibility

To replicate our analysis:

1. Ensure all dependencies are installed.
2. Open and run `main.ipynb`.
3. The notebook will automatically load:

   * `dataset.csv`
   * Trained models from the `mymodel/` directory
